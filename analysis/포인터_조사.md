# 포인터 전수 조사 결과

도구: `census2.py` (재귀 추적), `systext.py` (시스템 텍스트 테이블 탐색). 결과 목록: `pointers.csv` (3,228개).

## 1. 대사 블록 구조 (뱅크 $88~$8C)

대사는 **"포인터 테이블 + 바로 뒤에 이어지는 문자열들"**로 된 블록 단위로 저장됩니다.
포인터는 모두 **뱅크 내부 16비트**이고, 테이블의 첫 항목이 보통 테이블 바로 뒤를 가리킵니다.
테이블 끝의 남는 항목은 다음 블록의 테이블 주소로 채워져 있습니다(미사용 표시).

## 2. 전투 대사 명령 (뱅크 $88)

0x4031E 인덱스의 각 항목은 명령 하나를 가리킵니다.

- `FA 05 F7 n p1 … pn`: 대사 n개 중 무작위로 하나
- `FA 05 F9 p`: 대사 하나

여기서 나오는 포인터는 540개입니다(`pointers.csv`의 `quote`).

## 3. 문자열 안의 제어 코드 (인자 길이 확정)

| 코드 | 길이 | 의미(추정) |
|---|---|---|
| `F3` | 1 | 줄바꿈 |
| `F4` | 1 | 키 입력 대기 |
| `FA xx` | 2 | 이름 삽입 (`FA 04`/`FA 05` = 주인공·현재 파일럿 이름 등) |
| `FD xx` | 2 | 화자 얼굴 |
| `F6 a t` | 3 | `$80:D277` t번 표의 a번 항목 호출(이름 등) |
| `FB ffff` | 3 | 플래그 켜기/끄기 |
| **`F9 ffff pppp`** | 5 | **조건 분기** (플래그 워드 < $8000) |
| **`F9 pppp`** | 3 | **무조건 점프** (워드 ≥ $8000, 문자열 끝) |
| **`F8 06/07 pppp`** | 4 | **유닛 조건 분기** (F8 00~05는 포인터 없는 4바이트) |
| **`F7 n pp…`** | 2+2n | **무작위 분기** → 6개 |
| `FF` | 1 | 끝 |

`F9`와 `F7`의 포인터도 재배치할 때 함께 고쳐야 합니다.

## 4. 결과 요약

- 포인터 3,228개 (테이블 2,631 / 전투 대사 540 / F9 51 / F7 6)
- 문자열 2,442개, **대사 총 133,172바이트**
- 남은 미참조 텍스트
  - 0x54101, 0x5745A, 0x596B0: 짧은 대사 3개. 미사용이거나 다른 경로로 참조되는 것으로 보임
  - **0x6402E~0x64252 (오프닝 프롤로그), 0x642xx~0x65F31 (엔딩 리포트)**: 코드에서 직접 참조(예: 0x001601 부근). 프롤로그는 `F6 xx 6B`(스크롤 대기), `FE`(페이지)를 별도 의미로 사용 → ASM 확인 필요
